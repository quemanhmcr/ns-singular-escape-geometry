# Notation

- \(u\): divergence-free velocity field.
- \(\omega=\nabla\times u\): vorticity.
- \(P\): Leray projection onto divergence-free fields.
- \(F=P(u\times\omega)\): Euler/Lamb nonlinear forcing in projected rotational form.
- \(\Lambda=(-\Delta)^{1/2}\).
- \(E=\|u\|_2^2\): kinetic-energy norm (up to conventional factor 1/2).
- \(K=\langle u,\Lambda u\rangle=\|\Lambda^{1/2}u\|_2^2\): critical \(\dot H^{1/2}\) quantity.
- \(Z=\|\Lambda u\|_2^2\).
- \(M_3=\|\Lambda^{3/2}u\|_2^2\).
- \(M_4=\|\Lambda^2u\|_2^2\).
- \(m=K/E\): centered mean radial frequency.
- \(s=(\Lambda-m)u\): centered spectral escape direction.
- \(D=EZ-K^2=E\|s\|_2^2\): centered spectral defect.
- \(\delta=D/(EZ)=1-K^2/(EZ)\): normalized defect.
- \(\kappa=\langle s,F\rangle=\langle\omega,s\times u\rangle\): nonlinear escape production.
- \(\nu_E=\kappa/M_3\): Euler effective/anti-diffusive coefficient in viscosity units.
- \(\Gamma=\langle(\Lambda-m)^2u,F\rangle=-\langle s,[\Lambda,u\cdot\nabla]u\rangle\): second-centered spreading production.
- \(R=\Lambda^{-1}\operatorname{curl}\), \(u=u_++u_-\), \(Ru_\pm=\pm u_\pm\): helical decomposition.
